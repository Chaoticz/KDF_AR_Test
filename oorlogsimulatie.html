Voor iedereen

Public Game

De public game is beschikbaar voor iedereen. Het is snel en simpel. Vote voor een kit, map en gamerule en spelen maar.

Kit Voting

Vote voor de kit die jij wilt spelen. De kit met de meeste votes wordt gespeeld.

Map Voting

Vote voor de map die jij wilt spelen. De map met de meeste votes wordt gespeeld.

Gamerule Voting

Vote voor de gamerules die jij wilt spelen. De gamerule met de meeste votes wordt gespeeld.

Jouw game, jouw keuzes

Private Game

De private game biedt je de mogelijkheid om een oorlogsimulatie te spelen precies naar jouw wensen.

Kit Modification

Geen vaste kits. Jij kan de hele kit samenstellen zoals jij dat wilt.

Map Selection

Als host bepaal je eenvoudig welke map er gespeeld gaat worden.

Gamerule Modification

In plaats van te voten op een gamerule, kun je elke gamerule aanpassen naar jouw wensen.

Event Modification

Geen zin om te wachten op onze events? Speel een event zoals King of the Hill, Conquest, Nexus.

Geen limiet

Invite zoveel spelers als je maar wilt, er is geen limiet.

Realtime verzameld

Last Game Stats

Realtime wordt in jouw game allerlei statistieken verzameld zoals Kills, Deaths, KDR, Hits en Bow Hits.

Prestaties

Inventory

Public en Private

Leaderboards

Detailed Statistics

Public en Private

Overal geïntegreerd
